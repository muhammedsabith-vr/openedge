# OpenEdge

### RISC-V + INT8 AI Accelerator + Real-Time Robotics

## Overview

OpenEdge is a learning and engineering project exploring
computer architecture, RISC-V processors, INT8 AI acceleration,
embedded systems, and real-time robotics.

## Goals

- Learn digital logic and computer architecture
- Study the RISC-V instruction set architecture
- Build and test hardware using Verilog/SystemVerilog
- Design an INT8 multiply-accumulate (MAC) unit
- Explore CPU-to-accelerator communication
- Integrate embedded software and real-time control
- Eventually connect the system to sensors and robotics

## Development Roadmap

1. Digital logic fundamentals
2. Build an 8-bit ALU
3. Learn Verilog/SystemVerilog
4. Study RISC-V architecture
5. Build a simple CPU
6. Develop an INT8 MAC accelerator
7. Benchmark and optimize
8. Explore embedded AI and robotics

## Current Status

Stage 0: Learning foundations and setting up the development environment.
